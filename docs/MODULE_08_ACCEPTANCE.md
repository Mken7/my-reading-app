# 一级模块 08：章节、私人书签、字符级阅读进度与跨设备同步

**状态：开发分支功能与自动化验收（必须以最终 CI 成功为准）。正式应用尚未上线。**

这是 14 个一级模块中的第 08 模块的统一验收清单，不按子功能反复宣布完成。

## 本模块实现

1. **章节目录**：房主发布不能静默篡改的章节标题与已上传段落索引；成员只能在有效书房内按需查看和跳转。目录可能透露后续章节名，因此默认折叠，提示潜在剧透。
2. **独立私人标记**：每位读者在每间书房最多额外保存 20 处段落书签，每条可以自定义不超过 80 个字符的名称；可以独立更新名称、查看、跳转或二次确认移除。另一位读者不能查看或删除这些私人标记。
3. **字符级进度**：读者可在中文、emoji 等 Unicode 正文选区后点击“记住读到此字的位置”；数据库存放单个段落的 Unicode 码点偏移（不是 JS UTF-16 单位）和服务器修订号。换设备从书签继续时可定位到对应文字并滚动到可见位置，不会自动公开阅读位置。
4. **跨设备同步**：只同步当前读者自己的书签与进度；进度采用逐版本 compare-and-swap（CAS），旧设备不能悄悄覆盖新设备。每 45 秒及页面恢复焦点/可见时检查新位置。同源同账号不同标签页收到 BroadcastChannel 通知后主动拉取。没有实时在线状态追踪。
5. **冲突由读者决定**：发现其他设备的新进度时，不自动跳转阅读正文。读者可恢复服务器位置，或明确选择用当前段落与字符偏移覆盖；后者仍需要最新修订号匹配，若其他设备再次更新则再提示冲突。
6. **兼容旧版 V2**：原三参数的段落级保存接口仍可使用，旧接口改变段落时重置字符偏移到 0；新接口不会把非零预期修订误当首次创建。
7. **隐私权限**：相关表没有直接的普通用户 SQL 读写权限。可信数据库 RPC 使用登录身份与活动成员检查，拒绝陌生账号、匿名账号及已关闭书房。每个账号的游标/手工书签严格隔离。

## 尚未覆盖的上线验收

- iOS Safari、安卓 Chrome 真机触控选区、屏幕阅读器、复杂跨行重排的精确文字定位，以及真实双设备+独立 staging Supabase 用户流程，归入第 14 模块。
- 共读伙伴的实时在线状态、共同阅读追踪与防剧透权限属于第 10 模块；这里仅同步自己的私人位置。
- 本模块不是离线后台同步：若断网，服务器没有收到的进度不会自动写到本机明文队列。第 09 模块的加密待发送草稿专门服务于文字批注和回复，未擅自把阅读位置写入 localStorage。
- 账户删除、数据保留政策、版权限制和生产环境迁移属于其他一级模块。此功能仅在草稿 PR 中，不更新 main 或生产 Supabase。

**完成标准**：本模块约定的开发分支代码、严格构建、Node 单元测试、PostgreSQL 安全测试及 Chromium 同源通知测试全部通过；不应将此解释为完整应用的正式用户验收。
