# V2 章节、书签和重叠批注（隔离测试功能，尚未上线）

## 已提交的内容

- 章节目录：房主在完整 TXT/EPUB 分段上传后逐项登记目录。数据库校验房主身份、段落是否已上传和书房状态；既有条目不可静默修改，重试相同记录安全。
- 私人阅读进度与保存标记：每位登录读者都有独立的 Unicode 字符级阅读位置（段落、码点偏移、修订号），以及每间书房最多 20 处独立命名的私人书签。新设备修改时旧设备收到冲突，读者自行决定恢复还是确认覆盖；自动刷新只通知、不跳转。详细验收见 `docs/MODULE_08_ACCEPTANCE.md`。
- 独立批注：两人可以对相同或交叉的文本范围写不同笔记。服务器记录段落编号及 Unicode 码点区间，不禁止重叠；行级权限隔离私人/共享内容。
- 审计：文字批注新增和编辑都生成带上一条哈希的事件摘要；审计尚未外部签名锚定，不能保证拥有管理员权限者无法整链重写。
- 颜色：自己的文本选区为蓝色，伙伴为红色，两人交叉的范围为紫色。笔记正文按纯文本渲染，不解释 HTML。
