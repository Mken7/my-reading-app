## 汇总

- **功能开发工程估算：约 66%**（上述 14 项平均约 66.4%；分数是估算，不是质量承诺）。
- **正式上线准备：约 25%**。没有独立 staging Supabase 双人端到端、iOS/Android 真机全流程、上线迁移/回滚审查，不得当作已发布产品。
- **代码安全边界**：draft PR #1 内开发；不修改 main、备份分支、生产数据库；不上线也不使用付费服务。
- 03、04、05、06、07、08、09 的 100% 限于约定的代码与自动化测试验收；03 的入房审批需要真实 staging 多账号验证，04 是有明确上限的纯文字导入，扫描 OCR/原书视觉版式未承诺。真实环境的兼容性、部署和双账户 E2E 统一列入模块 14，不得对真实用户宣称完整测试。

以上基线在某一级模块正式验收结束后才调整；若验收发现缺陷，应回退其模块状态，而不是维持虚假 100%。
