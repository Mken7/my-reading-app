# V2 磨砂玻璃悬浮阅读中控（开发分支测试版）

该功能实现于 `app/v2/V2GlassDock.tsx` 和 `app/globals.css`，接入 `app/v2/V2ProtectedBook.tsx`。仅在独立 Supabase 测试项目启用 V2、登录并进入某个活动书房后才会显示。**这是 React 交互实现，不是仅有一张设计效果图。**

## 交互

- 默认悬浮磨砂圆球；点击或键盘操作可展开工具菜单，再次点击、按 Esc、点击菜单外或点“收起”关闭。
- 桌面：右侧中部竖向胶囊；手机：右下角浮球，上方打开 3 列网格小面板。两种尺寸都提供焦点样式和 ARIA 名称。
- 目录：展开已有章节目录，并滚动到相应位置；章节点击后仍走受权限控制的正文读取接口。
- 书签：定位到当前用户自己的进度面板，仍采用修订号避免跨设备静默覆盖。
- 批注：显示/隐藏当前正文的颜色划线、笔记列表与批注编辑面板。隐藏时只隐藏视觉层；保存的批注不会删除，未提交的文本也不会因切换而卸载丢失。
- 共读：查询有权读取的书房成员表，仅呈现房主/共读伙伴是否已加入。**不等于实时在线状态**。
- 设置：即时控制字号（14–24 px）、行距（1.5–2.3）和三种浅色纸张背景；仅对当前阅读页生效，不声称已做跨设备偏好同步。
- 一个时刻只打开一个活动书房阅读器，因此不会生成多个重叠的固定悬浮球。

## 可访问性与兼容性

- 菜单项是真正的按钮，支持 Tab、Enter/Space、Esc；可关闭焦点会返回悬浮球。
- 检测浏览器支持后使用 blur + saturate；不支持 backdrop-filter 时退回可读的接近实色背景。
- 响应系统的减少动画与减少透明度设置；按钮采用可见键盘焦点样式。
- 悬浮球固定在页面边缘，可能遮挡极窄屏上的正文区域。正式发布前还需要 iPhone、安卓与键盘/读屏器端到端测试，必要时增加移动/避让功能。
- 此版本暂不实现拖动悬浮球、滚动时自动半隐、动态液态变形、沉浸式全屏或跨设备保存界面设置。

## 验收状态

GitHub CI 验证 React / TypeScript 构建、严格 ESLint、TXT/EPUB/重叠区间单元测试和隔离 PostgreSQL 安全测试。

**CI 不代表界面已在真实手机上体验通过。** 正式上线前仍需测试 iOS Safari、安卓 Chrome、窄屏、多书房切换、读屏、触控选区及真实 Supabase 授权。此 PR 保持草稿，不合并 `main`，不变更线上 Supabase 数据。
