# 一级模块 07 · 自由手绘、图形批注与文字定位验收

**状态：开发分支代码与自动化验收完成（须以最终 CI 通过为准）；尚未上线。**

## 本一级模块实现的完整交付范围

- **三种图形批注：** 自由画、圆圈、箭头；鼠标及触摸 Pointer Events 统一采样，0–1000 归一化整数坐标，无效点、超长曲线或零长度图形会被拒绝。
- **选字定位：** 新笔迹必须绑定不可变正文的 Unicode 码点范围，不是浏览器 UTF-16 序号。可直接选中文字，也可通过键盘输入从 1 开始的起止字符序号；快速圈注和快捷箭头不要求拖动触控笔，键盘也可使用。
- **跨字体与屏幕重排：** 新笔迹采用单行文字锚点（`single_line_v2`），从 DOM Range 的真实可视行矩形测量位置。字号变化、屏幕缩放和文字标注 span 分段后重新定位。如果原文字重新排成**多行**，该形状会明确提示并**暂时隐藏**，不将圆圈或复杂曲线任意拉伸到多行；文字重新回到同一行会重现原图，数据库记录不丢失。绘图过程中发生跨行重排也无法误保存。此机制保证不伪装精确而失真的位置，不宣称支持任意跨行自由画的像素级重建。
- **历史兼容：** 老笔迹保留 `bounding_v1` 几何，既有整段缩放记录不修改不删除；旧版文字锚点仍可查看，暂不擅自推断并批量升级其布局类型。
- **两人分别保存：** 每条笔迹具备房间、段落、作者、私人或双方共享状态；本人蓝色、共读伙伴玫红色。不同人的同位置自由重叠且不会互相覆盖记录。只有活动书房成员可读自己或对方已共享的笔迹；陌生人、退出或关闭书房后不能继续访问。
- **笔迹管理及撤销：** 作者本人可逐条二次确认隐藏已保存笔迹，不能撤销对方内容；隐藏动作生成新的审计哈希链事件，旧的正文和点位受服务端保护但仍保留存储，**不是法律意义的彻底删除**。
- **配额与安全：** 每人每段最多保存 60 条笔迹，自由画 2–128 点，箭头和圆圈各 2 点；数据库验证时间戳、点位和文本码点界限，`anchor_layout` 只能使用允许的两种布局模式。新增的图形布局模式纳入创建审计摘要，旧版审计保持原样。
- **阅读状态：** 切回“阅读/选字”模式时，绘图 SVG 不截获普通文字选择、阅读滚动和触控；重排导致隐藏的形状仍会在“管理我保存的笔迹”中保留管理入口。
