# V2 手绘与笔记回复 · 隔离开发版

**未部署，不是正式版本。** 本功能仅在独立 V2 Supabase 测试项目启用时使用；旧网站仍保持原样。

## 本轮实现

- 在当前段落文字上方添加透明 SVG 图层，可选择画圈、箭头或自由曲线。支持鼠标与手机 Pointer Events 触控。阅读模式下 SVG 不截获触控，保留原本的选字和滚动。
- 每条形状独立保存书房、段落、作者、private/shared 和几何点位。坐标按当前段落矩形缩放至 0–1000，双方可在同一位置重叠，不能更改彼此的数据。
- 几何上限：自由曲线 2–128 点，箭头/圆圈各 2 点；每人每段最多 60 条笔迹。数据库触发器校验点位格式、整数范围、长度，防异常数据和存储爆炸。
- 在已存文字批注下按需展开回复：共享笔记可双方交谈，私人笔记只供本人续写。每个批注最多 100 条回复，仅展开时查询，避免一次加载整本书的讨论。只有具备访问权限的成员可以新增和查看回复。
- 新增手绘和回复都将摘要纳入房间的 SHA-256 哈希链，不能把该链误称为真正上链或绝对防篡改。

## 暂时的限制

- 图形使用段落区域的百分比坐标；改变字号、屏幕宽度、横竖屏或换行布局后，可能偏离原来的字句。它仍是画布批注原型，**尚不是排版变化后精确锚定的专业批注引擎**。
- 目前可清除未保存的笔迹，但不能在正式库中删除、编辑已经保存的笔迹或回复。删除和撤回必须补全审计、数据导出与权限规则，再考虑公开发布。
- 没有离线队列、实时多端推送、回复提醒、画笔颜色自定义、复杂手势防误触、无障碍绘图替代方式、自动法律审核或防批量注册的网络限流。
- 草稿 PR 不合并主分支，迁移不运行到正式 Supabase；当前不产生额外付费服务。
