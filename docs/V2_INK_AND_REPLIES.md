# V2 手绘与笔记回复 · 隔离开发版

**未部署，不是正式版本。** 本功能仅在独立 V2 Supabase 测试项目启用时使用；旧网站仍保持原样。

## 本轮实现

- 在当前段落文字上方添加透明 SVG 图层，可选择画圈、箭头或自由曲线。支持鼠标与手机 Pointer Events 触控。阅读模式下 SVG 不截获触控，保留原本的选字和滚动。
- 每条形状独立保存书房、段落、作者、private/shared 和几何点位。现在**新增的笔迹要求先选中文字**，同时保存 Unicode 码点范围（`anchor_start` / `anchor_end`）；文字换行或字号变化后，浏览器用 DOM Range 重新定位文字区域，再将形状按该区域缩放。双方仍可独立重叠，不会覆盖彼此。
- 升级前已有的无文字锚点笔迹保留原有整段比例坐标，不会删除或擅自重写。
- 几何上限：自由曲线 2–128 点，箭头/圆圈各 2 点；每人每段最多 60 条笔迹。数据库触发器校验点位格式、整数范围、长度，防异常数据和存储爆炸。
- 在已存文字批注下按需展开回复：共享笔记可双方交谈，私人笔记只供本人续写。每个批注最多 100 条回复，仅展开时查询，避免一次加载整本书的讨论。只有具备访问权限的成员可以新增和查看回复。
- 新增手绘和回复都将摘要纳入房间的 SHA-256 哈希链，不能把该链误称为真正上链或绝对防篡改。
- V2 新增「撤销我的笔迹」和「撤销我的回复」两次确认操作。只有原作者能调用受保护的 `v2_hide_ink` / `v2_hide_reply`，撤销后数据立刻不再通过普通用户的 RLS 查询显示，伙伴内容不会被删除。

## 验证

- 迁移按顺序：`supabase/migrations/20261019001000_v2_ink.sql`、`supabase/migrations/20261019002000_v2_note_replies.sql`、`supabase/migrations/20261019003000_v2_text_relative_ink.sql`、`supabase/migrations/20261019004000_v2_soft_hide.sql`（仅 V2 测试库）。最新迁移提供原作者专属撤销 RPC，撤销时间和操作者由数据库记录，并为每次成功撤销追加哈希链事件。
- 权限测试：`tests/sql/reading_hide_v2_smoke.sql` 串联此前所有 V2 测试，验证旧笔迹兼容、文字锚点、原作者才能撤销、陌生人和伙伴越权阻断、重复撤销幂等拒绝、撤销后的 RLS 不可见性、原始记录保留和审计链完整性。
- 单元测试：`tests/unit/ink.test.mjs` 与 `tests/unit/textAnchor.test.mjs` 验证归一化坐标、Unicode 与 emoji 在不同 React 文本节点之间的 UTF-16 转换、文字区域定位及不合法范围拒绝。
- CI 还必须通过严格 ESLint、TypeScript、Next.js 静态导出及此前的 TXT/EPUB/批注测试。
- **尚未进行真实 Supabase 测试账号及 iOS/安卓手机端到端测试。**

## 暂时的限制

- 新版图形相对**所选文字的外接矩形**定位，比整段缩放可靠，但跨行选区重新换行时，复杂曲线、圆圈仍可能拉伸或错位；旧笔迹也仍按整段比例显示。**不能宣称已实现对任意重排绝对精确的字形级锚定**。
- 现在可以通过受审计的 RPC **隐藏**自己已保存的笔迹/回复。原始数据仍留在受权限保护的数据库中，撤销不返还已消耗的笔迹或回复容量。**隐藏不等于彻底删除或履行个人信息清除请求**；真正的删除、保留期限、导出、监管协作和撤销后数据处理仍未设计。
- 没有离线队列、实时多端推送、回复提醒、画笔颜色自定义、复杂手势防误触、无障碍绘图替代方式、自动法律审核或防批量注册的网络限流。
- 草稿 PR 不合并主分支，迁移不运行到正式 Supabase；当前不产生额外付费服务。
