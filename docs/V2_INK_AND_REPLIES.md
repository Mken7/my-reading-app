# V2 手绘与笔记回复 · 隔离开发版

**未部署，不是正式版本。** 本功能仅在独立 V2 Supabase 测试项目启用时使用；旧网站仍保持原样。

## 本轮实现

- 在当前段落文字上方添加透明 SVG 图层，可选择画圈、箭头或自由曲线。支持鼠标与手机 Pointer Events 触控。阅读模式下 SVG 不截获触控，保留原本的选字和滚动。
- 每条形状独立保存书房、段落、作者、private/shared 和几何点位。现在**新增的笔迹要求先选中文字**，同时保存 Unicode 码点范围（`anchor_start` / `anchor_end`）；新笔迹只允许锚定同一行文字；改变字号时由 DOM Range 按文字行定位。文字重排成多行时，图形临时隐藏且提示用户，不会把圆圈/复杂曲线拉长到其他行。恢复单行后会重新显示。双方仍可独立重叠，不会覆盖彼此。
- 升级前已有的笔迹（含 `bounding_v1`）继续按原来的外接框比例绘制，不删除、不擅自重写；新笔迹使用数据库审核的 `single_line_v2` 布局模式并写入审计摘要。
- 除触控笔/鼠标绘制之外，支持键盘输入 Unicode 字符位置及一键圈注/箭头；不必依赖拖动画线。
- 几何上限：自由曲线 2–128 点，箭头/圆圈各 2 点；每人每段最多 60 条笔迹。数据库触发器校验点位格式、整数范围、长度，防异常数据和存储爆炸。
- 在已存文字批注下按需展开回复：共享笔记可双方交谈，私人笔记只供本人续写。每个批注最多 100 条回复，仅展开时查询，避免一次加载整本书的讨论。只有具备访问权限的成员可以新增和查看回复。
- 新增手绘和回复都将摘要纳入房间的 SHA-256 哈希链，不能把该链误称为真正上链或绝对防篡改。
- V2 新增「撤销我的笔迹」和「撤销我的回复」两次确认操作。只有原作者能调用受保护的 `v2_hide_ink` / `v2_hide_reply`，撤销后数据立刻不再通过普通用户的 RLS 查询显示，伙伴内容不会被删除。

## 暂时的限制

- 新版图形定位在**所选单行文本的矩形**，重排到多行时临时隐藏，不能进行任意跨行自由画的像素精确形状复现。旧笔迹仍按历史外接框显示。此方案优先确保不假装画线依然正确，**不能宣称已实现任意跨行专业图形重排**。
- 现在可以通过受审计的 RPC **隐藏**自己已保存的笔迹/回复。原始数据仍留在受权限保护的数据库中，撤销不返还已消耗的笔迹或回复容量。**隐藏不等于彻底删除或履行个人信息清除请求**；真正的删除、保留期限、导出、监管协作和撤销后数据处理仍未设计。
- 离线文字笔记队列已在第 09 模块实现，但**手绘笔迹**尚不能离线排队；还没有实时多端推送、回复提醒、自由画笔颜色选择、专业复杂手势或网络级限流。现有键盘选字及快捷圈注/箭头属于基础无障碍替代，真机屏幕阅读器仍需第 14 模块验收。
- 草稿 PR 不合并主分支，迁移不运行到正式 Supabase；当前不产生额外付费服务。
